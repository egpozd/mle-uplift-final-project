# О проекте

В проекте оценивается, как маркетинговое воздействие связано с откликом разных групп клиентов. Для этого сравниваются методы uplift-моделирования, которые оценивают различие отклика при разных вариантах воздействия.

## Данные

В наборе 64 000 наблюдений и 10 столбцов: признаки клиента, `treatment` и `target`. Целевой столбец трактуется как наблюдаемый бинарный отклик. По одним данным нельзя утверждать, что он означает покупку или использование промокода.

Распределения групп совпадают с распределениями в наборе Hillstrom: учебный `treatment=0`, вероятно, объединяет No E-Mail и Mens E-Mail, а `treatment=1` соответствует Womens E-Mail. Это вероятное соответствие, а не подтверждённое происхождение каждого столбца.

## Выполненная часть

Завершена первая часть проекта: проверены данные, проведён исследовательский анализ, выполнено разбиение на обучающую и тестовую выборки, обучены и сравнены S-Learner, T-Learner и X-Learner. Вторая часть пока не выполнена.

| Модель | Uplift@30% |
|---|---:|
| S-Learner | 0,036652 |
| T-Learner | 0,035919 |
| X-Learner | 0,034681 |

Наибольшее значение Uplift@30% получил S-Learner. Метрики относятся к сравнению Womens E-Mail с объединённой группой контроля и не дают отдельной оценки рассылки против её отсутствия.

## Как запустить

Требуется Python 3.10.12. В корне проекта выполните:

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyter notebook final_project_template.ipynb
```

## Файлы проекта

- `final_project_template.ipynb` — анализ данных и модели первой части.
- `uplift_fp_data.csv` — исходный набор данных проекта.
- `requirements.txt` — версии Python-библиотек.
- `utils.py` — вспомогательные функции проекта.
