# О проекте

В проекте сравниваются uplift-модели, которые помогают ранжировать клиентов по предполагаемому различию отклика при маркетинговом воздействии.

## Данные

В наборе 64 000 наблюдений и 10 столбцов: признаки клиента, `treatment` и `target`. Положительный отклик означает посещение сайта, а не покупку или использование промокода.

Построчное сопоставление с [открытым набором Hillstrom](https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html) подтвердило происхождение данных Практикума. `target` соответствует посещению сайта (`visit`), `treatment=1` — Womens E-Mail, а `treatment=0` объединяет Mens E-Mail и No E-Mail. Модель сравнивает эти группы; эффект рассылки относительно её отсутствия отдельно не оценивается.

## Выполненная работа

В первой части проверены данные, выполнен исследовательский анализ, обучены и сравнены S-Learner, T-Learner и X-Learner. Лучший Uplift@30% на test показала S-Learner.

| Модель | Uplift@30% на test |
|---|---:|
| S-Learner | 0,036652 |
| T-Learner | 0,035919 |
| X-Learner | 0,034681 |

Во второй части через Optuna подбирались параметры CatBoost и LightGBM. Также проверены дополнительные признаки и устойчивость результатов на другом разбиении обучающей выборки. Улучшение на второй проверке не подтвердилось, поэтому финальной осталась исходная S-Learner. Для неё построены uplift- и Qini-кривые, график по перцентилям и проверен класс инференса.

## Итоговые результаты

| Метрика финальной S-Learner на test | Значение |
|---|---:|
| Uplift@30% | 0,036652 |
| Uplift AUC | 0,022493 |
| Qini AUC | 0,050382 |

По шкале задания Uplift@30% соответствует удовлетворительному уровню. Тестовая выборка ранее использовалась для сравнения моделей в первой части, поэтому итоговая оценка не полностью независима от выбора S-Learner.

## Как запустить

Требуется Python 3.10.12. В Linux из корня проекта выполните:

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt notebook
python -m jupyter notebook final_project_template.ipynb
```

## Файлы проекта

- `final_project_template.ipynb` — анализ данных, сравнение моделей, подбор параметров, итоговая оценка, графики и класс для получения uplift-предсказаний.
- `uplift_fp_data.csv` — исходный набор данных проекта.
- `requirements.txt` — версии библиотек для анализа и моделирования.
- `utils.py` — функция построения графика uplift по перцентилям.
